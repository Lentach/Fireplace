Sealed

Signal protocol, every message

Double-ratchet end-to-end encryption by default — there is no unencrypted mode. Keys are generated and stay on your device; the server never sees them.

Yours

Self-hosted, no data brokers

Media lives on our own disk, not big-tech clouds. No ads, no analytics resale, no "partners". The code is public — read it instead of trusting us.

Ephemeral

Deleting actually deletes

Delete for everyone removes the message on both sides — server included. Edit window of 15 minutes, re-encrypted end-to-end like everything else.
