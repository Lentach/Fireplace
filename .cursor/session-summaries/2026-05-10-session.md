# Session summary — 2026-05-10

## What was accomplished

- Implemented **messenger-style long-lived sessions** without the full Phase 1 identity-key spec: **opaque refresh tokens** (365-day rolling TTL, **rotation** on use) + **24h access JWT**.
- **Backend:** `RefreshToken` entity, `RefreshTokensService` (SHA-256 storage), `POST /auth/refresh`, `POST /auth/logout`, login returns `{ access_token, refresh_token }`; **password change** revokes all refresh rows via `UsersService` + `RefreshTokensService.revokeAllForUser`.
- **Frontend:** `SharedPreferences` key `refresh_token`; `AuthProvider.ensureSessionReady()`, periodic refresh (15 min), cold-start + 401 paths; `ConnectionProvider.applyRefreshedAccessToken` wired from `MainShell`; `conversations_screen` awaits refresh before socket connect.
- **Docs:** `CLAUDE.md` session model + file map + DB constraint note for prod DDL.

## Follow-up (same day — blue theme bubble meta + local message time)

- **Issue:** Dark mode used `timeColorDark` (Wire/red-accent tint) for **all** dark themes; on **blue** sent bubbles (`mineMsgBgBlue`) time + disappearing countdown were low-contrast. Message clock used raw `DateTime.hour/minute` so **UTC** from API showed as wall time (e.g. 00:14 vs 02:14 in Poland).
- **Fix:** `RpgTheme.formatMessageClock(dt)` → `dt.toLocal()`; `RpgTheme.messageBubbleMetaColor(context, isMine)` — near-white on own bubbles, `FireplaceColors.mutedText` on received. Wired in `ChatMessageBubble`, `VoiceMessageContent`, `MessageMetadataRow`, `ConversationTile`.
- **Files:** `frontend/lib/theme/rpg_theme.dart`, `message_metadata_row.dart`, `chat_message_bubble.dart`, `voice_message_content.dart`, `conversation_tile.dart`, `CLAUDE.md`.
- **Verification:** `flutter analyze` (paths touched), `flutter test test/widgets/message/`; `graphify update .`.
- **Refinement:** Bubble meta colors apply **only** when `SettingsProvider.themePreference == 'blue'`; dark gray / light themes restored to `timeColorDark` / `textSecondaryLight`.
- **Local time globally:** `MessageDateSeparator` + `ChatDetailScreen._isDifferentDay` now use `toLocal()` for calendar-day chips and separators (not theme-specific).

## Follow-up (same day — PWA badge dropping 1 → none on second message)

- **Cause:** `onConversationsList` cleared `_unreadCounts` and overwrote with server `unreadCount`. `incrementUnreadCount` from a newer `newMessage` could run **before** a slightly older snapshot (reconnect / delayed `getConversations`), so the merged sum dropped and **`UnreadBadgeSync`** cleared the OS badge.
- **Fix:** Per conversation use **`merged = prev > serverUnread ? prev : serverUnread`** after capturing `previousUnread`; then force **`_activeConversationId`** unread to **0** so open-chat matches list snapshots that lag `markConversationRead`.
- **Files:** `frontend/lib/providers/conversations_provider.dart`, `frontend/test/providers/conversations_provider_test.dart`, `CLAUDE.md`; `graphify update .`.
- **Verification:** `flutter test test/providers/conversations_provider_test.dart`.
