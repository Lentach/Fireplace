# Session Summary — 2026-03-11

## Accomplished

1. **Chat freeze fix** — Ekran chatu zamrażał się po wejściu; użytkownik nie mógł pisać ani czytać wiadomości.
   - **Przyczyna:** Podwójne wywołanie `openConversation` (z `_openChat` i z `ChatDetailScreen.initState`) → dwa `getMessages` → dwa `messageHistory` → wielokrotne `_decryptMessageHistory` i pętla deszyfracji.
   - **Fix:** Na mobile `_openChat` tylko nawiguje; `ChatDetailScreen` wywołuje `openConversation` w `initState`. Na desktop nadal wywołujemy `openConversation` w `_openChat`.
   - **Dodatkowo:** Pomijanie wiadomości z `[Decryption failed]` przy ponownym deszyfrowaniu; anulowanie poprzedniego decrypt przy nowym `messageHistory`.

2. **Retry dla nieudanych wiadomości** — Przycisk Retry wywoływał `retryVoiceMessage` dla tekstu → błąd "Not a voice message".
   - **Fix:** `chat_message_bubble.dart` wywołuje `retryFailedMessage` zamiast `retryVoiceMessage`.

3. **UntrustedIdentityException** — Wysyłanie kończyło się błędem po rotacji kluczy.
   - **Fix:** W `encryption_service.dart` zapisujemy tożsamość z bundle przed `processPreKeyBundle`.
