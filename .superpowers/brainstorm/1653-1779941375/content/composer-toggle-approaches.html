Telegram-style: same slot, animated swap Recommended

Mic and send occupy the exact same 48×48 spot. Mic shows when text field is empty; send fades/scales in when user types. Mic GestureDetector stays mounted (invisible + non-interactive when send is shown).

Pros

  • Zero layout shift — slot is always 48×48
  • Send button wrapped in Focus(canRequestFocus:false) → no keyboard jump
  • Mic GestureDetector never unmounts (CLAUDE.md constraint satisfied)
  • Identical to Telegram / Zangi / WhatsApp

Cons

  • RecordingController needs 2 new props: showSend + onSend
B

Send next to mic (always visible)

Send button sits to the left of the mic at all times. Both are always rendered. Send is disabled/greyed when text is empty.

Pros

  • Simplest to implement — just add a button
  • Both affordances always visible

Cons

  • Composer row is wider — feels cluttered on compact screens
  • Not the Telegram/Zangi style you described
  • Row width change causes minor layout recalc
C

WhatsApp-style: send replaces field trailing icon

The send button appears inside the text field as a trailing icon (suffix). Mic stays external to the field. Send icon inside field fades in when typing.

  • Mic always visible and accessible
  • Send is inside field — clear visual pairing

Cons

  • Field width shrinks when send icon appears → text reflows
  • InputDecoration suffix is tricky with multiline TextField
  • More complex hit testing inside field
