- **Production outbound-send “only one user” bug:** Diagnosed as `WsThrottlerGuard` on `sendMessage` using the global **100 sends / 15 min per user** limit — a heavy sender could exhaust it and be unable to message anyone until the window slid; incoming messages still worked. **Fix:** `@Throttle({ default: { limit: 300, ttl: 900000 } })` on `handleSendMessage` in `chat.gateway.ts`; `CLAUDE.md` updated.

- **Chat keyboard jump on in-app send:** Tapping the app Send button cleared the field → `hasText` became false → idle UI swapped the send `IconButton` for the mic widget in the same frame, unmounting a sibling of the `TextField` and dismissing the soft keyboard (then `requestFocus` brought it back → “jump”). IME Send did not swap widgets. **Fix:** When not recording, `RecordingController` always mounts mic + send in a `Stack` and toggles visibility with `Opacity`/`IgnorePointer` instead of conditional children.
